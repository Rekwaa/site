# cv.rekwa.xyz

Site CV personnel — minimaliste, sombre, statique.

## Stack
- HTML/CSS/JS pur (zéro dépendance)
- Hébergé sur GitHub Pages
- Domaine : cv.rekwa.xyz (via Cloudflare)

## Modifier le site

Édite simplement `index.html` (le contenu) ou `style.css` (le style), puis :
```bash
git add .
git commit -m "update content"
git push
```
Le site se met à jour automatiquement en ~30 secondes.

## Tester en local

```bash
python3 -m http.server 8000
# Ouvre http://localhost:8000
```
