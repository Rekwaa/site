# rekwa.xyz

Page d'accueil (hub) sur le domaine racine `rekwa.xyz`.
Lie vers `cv.rekwa.xyz` et `write-ups.rekwa.xyz`.

## Stack
- HTML/CSS/JS pur (zéro dépendance)
- Hébergé sur GitHub Pages
- Domaine : rekwa.xyz (apex, via Cloudflare)

## Modifier le site

Édite simplement `index.html` ou `style.css`, puis :
```bash
git add . && git commit -m "update" && git push
```

## Tester en local

```bash
python3 -m http.server 8000
# Ouvre http://localhost:8000
```
